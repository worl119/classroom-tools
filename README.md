# Classroom Tools

수업 중 프로젝터에 띄워 쓰는 정적 웹 도구 모음. 빌드 과정이 없고, 각 도구는
외부 의존이 전혀 없는 HTML 파일 한 장입니다 — 한 번 열리면 네트워크가 끊겨도 돕니다.

## 도구

| 경로 | 이름 | 설명 |
|---|---|---|
| `clock/` | Clock | 시계 + 카운트다운 타이머 |

### Clock 조작

시계 화면

| 키 | 동작 |
|---|---|
| `T` | 타이머로 전환 |
| `S` | 초 표시 켜기/끄기 |
| `D` | 날짜 표시 켜기/끄기 |
| `H` | 12시간 ↔ 24시간 |
| `F` (또는 더블클릭) | 전체화면 |

타이머 화면

| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `R` | 초기화 |
| `↑` `↓` | ±1분 (`Shift` 함께 누르면 ±5분) |
| `T` / `Esc` | 시계로 |

프리셋 버튼(1·2·3·5·10·15·20분)을 클릭하면 즉시 시작합니다. 남은 시간이 1분 이하면
숫자가 주황, 0에 닿으면 빨강으로 바뀌고 초과분을 계속 셉니다. 알림음은 없습니다.

표시 설정(초·날짜·12/24시)은 브라우저에 저장되어 다음에도 유지됩니다.

## 배포

GitHub Pages. `main` 브랜치의 루트를 그대로 서빙합니다 — 커밋을 밀면 배포됩니다.

`https:`로 접속해야 화면 꺼짐 방지(Screen Wake Lock)가 작동합니다. 프로젝터 화면이
수업 도중 잠들지 않게 하는 기능이라, 로컬 파일(`file://`)로 열면 이 부분만 빠집니다.
